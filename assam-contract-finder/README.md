# Assam Contract Finder

Mobile-first tender finder for Assam government and Railway/NFR opportunities.

This project starts with official-source links and a FastAPI collector for the public Assam eProcurement homepage. It does not bypass CAPTCHA, login, or anti-bot controls.

Official sources:
- https://assamtenders.gov.in/
- https://www.ireps.gov.in/

The Android build is handled by GitHub Actions.
