# LeadPilot AI — Coaching Enquiry Automation Demo

A zero-cost prototype for demonstrating an AI-powered enquiry and lead-capture service to local coaching institutes.

## Demo features
- Student enquiry chat interface
- Quick answers for courses, fees, batches, timings and admissions
- Lead capture form
- Simple owner-facing lead dashboard
- Responsive design
- No API keys or paid services required

## Suggested introductory offer
- ₹2,999 setup
- ₹999/month management

These are starting-point examples, not fixed pricing.

## Run
Open index.html in a browser. No build step is required.

## Production roadmap
1. Connect a real AI provider through a server-side API.
2. Add WhatsApp Business integration.
3. Store leads in a real database.
4. Add owner notifications.
5. Add institute-specific course/fee/FAQ configuration.
6. Add authentication and audit logs.
